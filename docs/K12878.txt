 K12878: Generating diagnostic data using the qkview utility
Published Date: Oct 2, 2015Updated Date: Aug 19, 2026

    Download Article

Topic

    You want to verify the proper operation of your BIG-IP or BIG-IQ system by uploading a QKView file to F5 iHealth.
    You want to provide a QKView file to F5 Support to aid in troubleshooting an issue with a BIG-IP or BIG-IQ system.

    Note: This article applies to the BIG-IP and BIG-IQ systems, including the BIG-IP and BIG-IQ tenants running on the VELOS system. For information about generating diagnostic data for the VELOS system, refer to K02521182: Generating diagnostic data for the VELOS system using the qkview utility.

For more information, refer to: K000134919: Error message when uploading QKView from BIG-IP and Bug ID 1225789: The iHealth API is transitioning from SSODB to OKTA.

Description

The qkview utility is a program that you can use to automatically collect configuration and diagnostic information from BIG-IP or BIG-IQ systems.

The qkview utility is an executable program that generates machine-readable (XML) diagnostic data and combines the data into a single compressed Tape ARchive (TAR) format file. You can upload this file, called a QKView file, to F5 iHealth , or give it to F5 Support to help them troubleshoot any issues.

Note: F5 Support requires a QKView file in all cases in which remote access to the product is not available.

Note: If you are transferring the generated qkview file off the BIG-IP or BIG-IQ system to a remote system, you may want to refer to K58243048: Considerations for transferring files from F5 devices for a better understanding of the general security implications. You may also want to refer to K55559493: Obfuscating sensitive data in a QKView file for options on generating a qkview file that includes sensitive data.

Prerequisites

You must meet the following prerequisites to use these procedures:

    You have administrator or resource administrator access to the Configuration utility.
    You have an F5 support site single sign-on (SSO) account to access the F5 iHealth diagnostics server.
    You have root access to the BIG-IP command line.

Running the qkview utility from the Configuration utility (BIG-IP)

To run the qkview utility from the BIG-IP Configuration utility, perform the following procedure:

Impact of procedure: The qkview utility runs a large number of commands when collecting information. This behavior may cause an additional performance burden on systems that are already under heavy load.

    Log in to the Configuration utility.
    Go to System > Support.
    Select New Support Snapshot.
    For Health Utility, select Generate QKView.
    Select Start. Wait for the system to complete the generation of a QKView; once the QKView is successfully generated, the system would list the completed date and time of the QKView in the Last Generated Snapshot section.
    To download the output file, select Download.

Note: Starting in BIG-IP 13.1.0, you can override the default 5 MB maximum log file size of the QKView by selecting the Unlimited snaplen check box in the QKView Options section prior to selecting Start. Overriding the default size limit can result in very large QKView files. You should only use this option when instructed to do so by F5 Support.

Running the qkview utility from the command line (BIG-IP or BIG-IQ)

Impact of procedure: The qkview utility runs a large number of commands when collecting information. This behavior may cause an additional performance burden on systems that are already under heavy load.

    Log in to the command line.
    To run the qkview utility, enter the following command:

    qkview

    The output file name displays after the command has completed.
    Collect the output file from the /var/tmp/ directory by copying the file to an external host using a utility such as ftp or scp.

Note: You may also run qkview by using the tmsh run /util qkview command.

Using qkview command-line options

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

    To view the list of qkview command line options, enter the following command:

    qkview -h

    For example, to reduce the performance burden of qkview, you can run qkview at the lowest possible priority by entering the following command:

    nice -n 19 qkview

    Note: For heavily loaded systems, qkview may take a long time to finish running when using the nice -n 19 option.
    To run the qkview command and specify the file size allowed, use the qkview -s option.

    For example, to increase the file size limit as explained at K23928121: Overview of qkview command-line options, enter the following command:

    qkview -s 0

Running a QKView file from the Configuration utility and uploading it to F5 iHealth (BIG-IP 13.0.0 and later)

Beginning in BIG-IP 13.0.0, you can upload a QKView file directly to the F5 iHealth server from the BIG-IP system. Before performing this procedure, ensure that you have your F5 Support SSO account credentials available and that your BIG-IP system has internet access the following services. If you do not have an existing account, refer to K000089224: Register for an F5 account for information about registering for one.
Host Name	Remote Service/Port
api.f5.com
ihealth-api.f5.com	HTTPS/443

Impact of procedure: The qkview utility runs a large number of commands when collecting information. This behavior may cause an additional performance burden on systems that are already under heavy load.

    Log in to the Configuration utility.
    Go to System > Support.
    Select New Support Snapshot.
    For Health Utility, select Generate and Upload Qkview to iHealth.
    Enter your iHealth clientID and iHealth secret.
    Optional: For Support Case (SR) Number, enter the number of the active F5 Support case.
    Select Start.

Note: For more options introduced in the qkview utility, refer to K23928121: Overview of qkview command-line options and K55559493: Obfuscating sensitive data in a QKView file.

Note: If you are transferring the generated qkview file off the BIG-IP or BIG-IQ system to a remote system, you may want to refer to K58243048: Considerations for transferring files from F5 devices for a better understanding of the general security implications.

Running the qkview utility from BIG-IQ user interface

Impact of procedure: Performing the following procedure should not have a negative impact on your system.

    Log in to the BIG-IQ user interface.
    Go to System > This Device > BIG-IQ iHealth > Configuration.
    Select Add.
    Enter the clientID and secret for your iHealth account.
    Select Save & Close.
    Go to System > This Device > BIG-IQ iHealth > Tasks.
    Select QKView Upload.
    Enter the name, description, and F5 Support case number, then choose the credential for the QKView file upload.
    Select Save & Close.

Uploading a QKView file to F5 iHealth

After you obtain the QKView diagnostic file, you can upload the file to F5 iHealth to diagnose the health and proper operation of your BIG-IP or BIG-IQ system. To do so, perform the following procedure:

Impact of procedure: The qkview utility runs a large number of commands when collecting information. This behavior may cause an additional performance burden on systems that are already under heavy load.

    Open a web browser and log in to the F5 iHealth site.
    Select Upload.
    Select Choose.
    Go to the QKView file on your local system.

Note: As an alternative to using F5 iHealth, you can also provide the QKView file to F5 Support. To do so, refer to K000090853: Exchange files with F5 Support using MyF5.
