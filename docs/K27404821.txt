 K27404821: Using F5 iHealth to diagnose vulnerabilities
Published Date: Aug 27, 2018Updated Date: Jul 7, 2026

    Download Article

Topic

F5 discloses Common Vulnerabilities and Exposures (CVEs) for F5 products in Monthly Security Notifications (MSNs). Check your BIG-IP, BIG-IQ, F5OS-A, or F5OS-C systems for known vulnerabilities on a regular basis and consider scheduling your audits to align with MSN disclosures. You can do this by uploading a QKView file from your system to F5 iHealth, which enables you to review system diagnostics.

Description

iHealth automatically runs all F5 custom diagnostics against your system configuration data after you upload the QKView file to the iHealth system. The results are easily accessible by navigating to Diagnostics in iHealth.

You can use iHealth to check for the following known vulnerability types on BIG-IP, BIG-IQ, F5OS-A, and F5OS-C systems:

    F5 security vulnerabilities
    F5 security exposures
    Third-party security vulnerabilities that affect F5 systems

In addition, iHealth Diagnostics evaluates the logs, command output, and configuration of your systems against a database of known issues, common mistakes, and published F5 best practices. The prioritized results provide tailored feedback about configuration issues or code defects and provide a description of the issue, recommendations for resolution, and a link to more information on MyF5.

Prerequisites

You must meet the following prerequisites to use these procedures:

    You have administrative access to the system.
    You have an F5 support site single sign-on account.
    You have Internet access through which to submit your QKView files to iHealth.

Procedures

    Generate a QKView file on your system and upload it to iHealth
    Review iHealth Diagnostics to determine potential system vulnerabilities
    Review diagnostics results for a specific virtual server, profile, or pool
    Remediate vulnerabilities

Generate a QKView file on your system and upload it to iHealth

The qkview utility is an executable program that generates machine-readable XML diagnostic data and combines the data into a single compressed Tape ARchive (TAR) file called a QKView. You can upload the QKView to the iHealth system, which translates the output and displays the content in a format similar to that of the Configuration utility. For detailed instructions about generating a QKView and uploading it to iHealth, refer to the following articles:

Review iHealth Diagnostics to determine potential system vulnerabilities

iHealth Diagnostics evaluates the logs, command output, and configuration of your systems against a database of F5 security vulnerabilities and exposures, some third-party vulnerabilities, known issues, common mistakes, and published F5 best practices. After you log in to iHealth you can review vulnerabilities to which your device may be susceptible.

Impact of procedure: There is no impact to your system.

    Log in to iHealth.
    Open the QKView file you uploaded by selecting the Hostname for your device.
    Go to Diagnostics.

    Review vulnerabilities identified for your device configuration.

Note: The heuristics listed when the passed check box is enabled under Diagnostics >> Status are iHealth heuristics that do not match qkview data.

Review diagnostics results for a specific virtual server, profile, or pool

iHealth Config Explorer allows you to search your system’s configuration for specific objects, including virtual servers, pools, iRules, policies, nodes, monitors, and profiles. After the tool completes a search of your QKView file, the Config Explorer highlights known issues, common mistakes, and published F5 best practices.

    Open the QKView file you uploaded by selecting the Hostname for your device.
    Go to Config Explorer.
    Select LTM.
    Select the type of object you want to check for vulnerabilities.
    Filter the results to find the configuration object you want to verify.
    Select the name of the configuration object.
    Select the Diagnostics tab.

    Review all identified vulnerabilities or potential issues for this specific configuration object.

Remediate vulnerabilities

Each diagnostic result includes a summary of the identified issue, a suggested action to address the issue, links to further information about the issue (such as MyF5 articles) and the heuristic name.

Select the down arrow icon to expand the details for the diagnostic. F5 recommends that you refer to the linked MyF5 article to determine if your device is known to be vulnerable, to see which components or features are affected by the vulnerability, and to find additional information about releases, hotfixes, or corrective actions to address the vulnerability.

In most cases the customized diagnostic information enables you to take the recommended action, and, in many cases, it can help you resolve common configuration issues without the need to contact F5 Support. If you require assistance from F5 Support, your iHealth data is available to F5 engineers through iHealth for faster resolution.
