 K15202: IP addresses for F5 hosted services
Published Date: Sep 18, 2015Updated Date: Oct 2, 2026

    Download Article

Topic

Best practices may dictate that you use fixed IP addresses when setting firewall policies, instead of using host names that are resolved by DNS. The table in the following section includes ranges of IP addresses that network administrators can use to correctly configure firewalls, allowing access to F5 services.
Description

F5 services are not bound to a single IP address only. You can perform a name resolution (for example, using nslookup) to verify the IP address of the desired F5 service at any given time. The output of the nslookup command should display an IP address that is within the specified range.

Recommendations

When you configure firewalls to allow external access to external F5 services, you should consider the following factor:

    IP address ranges may change or be amended in the future.
